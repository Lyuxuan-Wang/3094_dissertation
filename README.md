# CNN-based Image Super-Resolution and Denoising for Rendered Images

## Overview
This project evaluates CNN-based super-resolution (EDSR) and 
denoising (FFDNet) as offline post-processing methods for 
path traced rendered images, comparing them against traditional
baselines (bicubic interpolation and CBM3D)

## Requirements
Python 3.14 is required.

Install dependencies with: pip install -r requirements.txt

## Pre-trained Models
Here are links,

For EDSR:
https://github.com/XPixelGroup/BasicSR

For FFDNet:
https://github.com/cszn/KAIR

## Dataset
Ground truth images were rendered in Blender using three benchmark scenes
(Lone Monk, Classroom, Lynxsdesign) at 1024 spp, 1024×1024 resolution.
Degraded inputs (LR, GN, RN) are generated by the pipeline from the ground
truth images.

Benchmark scenes can be found here:
https://www.blender.org/download/demo-files/

## Running the Experiment
python run_experiment.py

Results will be saved to `results/` and evaluation metrics to
`metadata/evaluation.csv`.
